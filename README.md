# 🧾 Trackizer – Personal Finance & Subscription Tracker

Trackizer is a **cross-platform Flutter application** designed to help users manage daily expenses, track subscriptions, and gain insights into their financial habits. Built with a clean, modern UI and scalable architecture, Trackizer aims to be a foundation for a full personal finance ecosystem.

---

## 🚀 Features

* **Modern & Responsive UI** using Flutter (Android, iOS, Web, Desktop)
* **Subscription Tracking**: View, add, and organize recurring expenses
* **Expense Overview**: Visual breakdown of spending trends (UI-ready)
* **Modular Architecture** prepared for backend integration
* **Custom Widgets**: `HomeView`, `UpcomingBillRow`, `SubscriptionHomeRow`
* **Clean & Maintainable Codebase** following Flutter best practices

---

## 🏗️ Tech Stack

* **Framework:** Flutter (Dart)
* **State Management:** Provider (extendable)
* **UI Toolkit:** Material Design + Custom Widgets
* **Architecture:** Component-based, scalable structure

---

## 📂 Project Structure

```
lib/

 │    └── splash/          # Splash screen logic
```
